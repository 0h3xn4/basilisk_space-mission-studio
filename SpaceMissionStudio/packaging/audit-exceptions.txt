# Known advisories CI's pip-audit step accepts (packaging/constraints.txt).
#
# pillow 12.2.0: the qualified Basilisk, bsk 2.12.0, requires
# pillow<=12.2.0 (its own metadata), so no fixed pillow can be installed
# with it. Every advisory below but one is about decoding a crafted image
# file.
# Neither SpaceMissionStudio nor the Basilisk modules it uses decodes an
# image with pillow (no Image.open, imread or imsave in either); pillow
# is loaded only because Basilisk imports matplotlib for its plots.
# The one, PYSEC-2026-4363 (CVE-2026-112902, found 2026-11-11), is about
# encoding instead: pillow's libtiff encoder can leak process memory into
# a compressed TIFF it writes from crafted metadata. Neither
# SpaceMissionStudio nor those Basilisk modules writes a TIFF, or any
# image, with pillow: the app's plots are drawn and saved (PNG, SVG) by
# plotly.js in Qt WebEngine.
# Two more TIFF ones, found 2026-11-15: CVE-2026-128067 (GHSA-xcvg-w56q-
# r89m), the libtiff encoder reading or writing past a heap buffer when
# saving a compressed TIFF whose tags override the image size, and
# CVE-2026-128066 (GHSA-wqgw-9xfh-qf2g), Image.open of a crafted TIFF or
# EXIF block taking thousands of times its size in memory. The same holds:
# no TIFF is read or written with pillow. The one pillow user in the
# repository, scripts/prepare_mission_view_textures.py (a maintainer's
# script, not shipped), opens two PNG textures after checking their
# SHA-256 against the recorded values.
# Remove these lines with the Basilisk upgrade that allows pillow >= 13.0.0;
# tests/test_dependencies.py fails if pillow is moved and they are not.
#
